A developer companion for the maproj infrastructure and Modern Apps builds

Features:
- Browse the maproj git host: repositories, refs, issues, pull requests and CI test status
- Read repository files with line numbers via the mirrored source tree
- See every available Modern Apps build in the read-only F-Droid catalog
- Receive server-pushed dev builds over a paired WebSocket and install them with one tap

Internet only used for: the maproj git host, CI status, the dev-build catalog and pushed installs
