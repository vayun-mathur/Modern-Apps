A logic gate puzzle game: start with NAND, end with a working computer

Features:
- 28 levels across five chapters, from NOT and XOR through adders, an ALU, registers and RAM to a CPU
- Finish by wiring your own CPU to memory and running real programs on it
- Every level is checked by a real cycle-accurate simulator, with no shortcuts
- Phone-first editor: tap a chip to add it, drag from a pin to wire, pinch to zoom, undo and redo
- Multi-bit buses with split and join chips
- Live wire values, and a test table you can step through row by row
- Stars for beating each level's NAND-count par
- Achievements, with progress reported to MA GameHub
