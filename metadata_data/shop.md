Discover UCP merchants and review shopping checkouts

Shop supports shopping through compatible merchants that advertise Universal Commerce Protocol services. Search Shopify Global Catalog where anonymous access is available, enter a merchant domain, or explicitly browse the public UCPList merchant directory.

Shop checks each merchant's live profile instead of guessing API addresses. Supported dated profiles use REST or negotiated MCP services, including JSON and supported streaming responses. Directory listings and badges are discovery leads, not a promise of access or payment authorization.

Refresh products before adding available integer-quantity variants to the cart. Keep merchant and currency totals separate, review merchant-returned buyer and fulfillment requirements, and see authoritative checkout totals and legal links where supported.

Payment continues on the merchant's site. Checkout sessions remain pending and cart items stay intact through browser handoffs or partial failures. Preparing a session or reopening a checkout link does not confirm a paid order.

Native payment completion requires a supported payment handler, provider approval and authorized merchant access. It is not enabled without those prerequisites; unsupported merchant requirements fall back to the merchant's website.
