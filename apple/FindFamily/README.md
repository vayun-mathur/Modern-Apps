# FindFamily for iOS

Source for the FindFamily iOS app, part of [Modern-Apps](https://github.com/vayun-mathur/Modern-Apps).
Issues: https://github.com/vayun-mathur/Modern-Apps/issues

Build on a Mac with `xcodebuild -scheme FindFamily -destination 'generic/platform=iOS' build`, or anywhere with the
[xtool fork](https://github.com/vayun-mathur/xtool) via `xtool dev build`. See `AGENTS.md` for versioning and release.
