Keep Modern Apps OS up to date with verified over-the-air system updates

Features:
- Checks automatically for new system builds and installs them in the background
- Applies updates to the inactive A/B slot, so a failed update leaves the device bootable
- Every package is signature-verified against the device's own release key before it is written
- Incremental updates when available, so a routine update is tens of megabytes rather than gigabytes
- Restarts only when the device is idle, never mid-use
- Stays off metered connections unless you allow it

Internet only used for: checking for and downloading system updates
