A lightweight, open-source code editor for Android

Features:
- Syntax highlighting from a native tree-sitter engine, with a regex fallback
- Folder-based project browsing via Storage Access Framework
- Git source control with staging, commits, branches, and diffs
- Find and replace across files
- Multiple open tabs with undo/redo, plus a command palette and terminal
- Handles VIEW/EDIT intents from other apps

100% offline
