A basic passwords app

Features:
- Encrypted database, stored behind biometric keys
- Import from Bitwarden, Chrome, Firefox, LastPass, 1Password, Dashlane and more
- Save and use passkeys as an Android credential provider
- Fills passwords into other apps as an autofill service
- Sync to a KDBX file of your choosing
- Acts as a security key for a desktop browser over Bluetooth (FIDO caBLE)

Internet only used for: acting as a security key for a desktop browser
